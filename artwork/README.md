# Application artwork

`lupin-icon-master.png` is the approved native 32×32 master. Run
`scripts/export_icons.py` from the repository root to produce the PNG/SVG exports
in `price_lens/resources` and the Windows ICO in `packaging`.

`classic-price-lens-icon-master.png` is the former leaf/magnifier artwork, retained
only for provenance. It is not used by the exporter or current packages. See
[artwork notes](../docs/ARTWORK.md) for the current assets and attribution.

Rejected previews remain local and are excluded from version control and release packages.
