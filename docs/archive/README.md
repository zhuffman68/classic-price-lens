# Documentation archive

These files preserve historical design, patch and handoff evidence. Versioned
commands, process IDs, paths, upload holds and UI descriptions describe their own
time; they are not current operational instructions.

- [Change notes](../CHANGELOG.md) index the retained patch records.
- [Developing Lupin](../DEVELOPING.md) describes the current source workflow.
- [Technical details](../TECHNICAL.md) describe current behavior and boundaries.
- [Verification](../../VERIFICATION.md) retains test evidence and platform limits.

The archive is source-only and is not staged into application packages. Old media
plans include example filenames that were never published; the README embeds the
actual approved demonstration assets.
