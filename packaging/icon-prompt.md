# Lupin icon exports

The approved artwork and export rules are documented in
[Lupin artwork](../docs/ARTWORK.md).

The canonical master is `artwork/lupin-icon-master.png`. Export it through
`scripts/export_icons.py`; the PNG/SVG outputs live in `price_lens/resources` and
the Windows ICO is `packaging/icon.ico`. `packaging/icon-master.png` is a retained
copy of the historical leaf/magnifier icon, not a current build input. Do not use
it to regenerate current icons.
